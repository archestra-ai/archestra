# Archestra MCP UI Integration Demo

This demo showcases the full integration of MCP UI support in Archestra, covering all four steps required by the bounty.

## Step 1: Archestra Chat UI Support

The Chat UI now detects and renders interactive UI components from MCP servers.

**Key Features**:
- **Automatic Detection**: Detects `_meta.ui.resourceUri` in tool results.
- **Sandboxed Rendering**: Renders UI in a secure iframe.
- **Bidirectional Communication**: Implements the full postMessage protocol.

**Demo**:
1. User asks: "Show me the weather in Tokyo"
2. Agent calls `get_weather` tool.
3. Tool returns a UI resource:
   ```json
   {
     "type": "resource",
     "resource": {
       "uri": "https://weather-mcp.ui/tokyo",
       "_meta": { "ui": { "resourceUri": "https://weather-mcp.ui/tokyo" } }
     }
   }
   ```
4. Archestra renders an interactive weather widget instead of raw JSON.

## Step 2: MCP Gateway Support

The MCP Gateway preserves UI metadata and routes interactive actions.

**Key Features**:
- **Metadata Preservation**: Ensures `_meta.ui` survives the RPC boundary.
- **Action Routing**: Routes `tool` and `prompt` actions from the UI back to the gateway.
- **Discovery**: Exposes UI capabilities in the `tools/list` endpoint.

**Demo**:
- 3rd-party UI connects to Archestra MCP Gateway.
- Gateway returns tools with UI metadata.
- 3rd-party UI renders the same interactive components.

## Step 3: LLM Gateway Support

The LLM Gateway normalizes UI resources generated by LLMs.

**Key Features**:
- **Normalization**: Ensures LLM-generated UIResources are consistent.
- **Consistency**: Presents the same interface as the MCP Gateway.

**Demo**:
- LLM generates a UI resource directly in its response.
- LLM Gateway normalizes it for the frontend.
- Chat UI renders the interactive component seamlessly.

## Step 4: Real MCPs in Catalog

Two test MCPs have been added to the Archestra catalog to demonstrate different UI capabilities.

### 1. Test Simple UI
- **Tool**: `show_html`
- **Capability**: Renders static HTML resources.
- **Use Case**: Documentation, simple reports, static visualizations.

### 2. Test Interactive UI
- **Tool**: `show_interactive`
- **Capability**: Full postMessage support for dynamic interactions.
- **Use Case**: Forms, interactive charts, complex dashboards.

## Technical Implementation Details

### Frontend
- `MCPUIRenderer`: Core component for iframe management and postMessage handling.
- `mcp-ui-utils`: Utilities for resource detection and validation.
- `ToolOutput`: Integrated UI rendering into the standard tool output flow.

### Backend
- `mcp-gateway-ui`: Enhanced gateway to preserve UI metadata.
- `llm-gateway-ui`: Normalized LLM responses for UI consistency.
- `mcp-gateway.utils`: Integrated UI support into the main gateway logic.

## Conclusion

Archestra now provides a first-class experience for interactive MCP tools, breaking the "text wall" and enabling rich, interactive agentic workflows.
