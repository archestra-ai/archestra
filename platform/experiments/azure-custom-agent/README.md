## Local Setup

Create an .env, then:

```bash
uv venv
uv pip install -r requirements.txt
uv run python azure_agent_with_archestra.py
```

## Deploy to Azure (One Command)

```bash
# Login to Azure
az login

az containerapp up \
    --name azure-agent \
    --resource-group anna.shishlyakova_rg_1472 \
    --location eastus \
    --environment my-env \
    --ingress external \
    --target-port 8000 \
    --source .

# Set environment variables
az containerapp update -n azure-agent -g anna.shishlyakova_rg_1472 \
  --set-env-vars \
    AZURE_AUTH_METHOD=azure_cli \
    ARCHESTRA_AGENT_ID=your-agent-id \
    USE_ARCHESTRA=true
```

The app will run at: `https://<auto-generated-name>.azurewebsites.net`
