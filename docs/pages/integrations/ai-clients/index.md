Give your existing assistant access to the tools your organization runs through Archestra.

Setup depends on where the client runs:

- Terminal clients use a setup command and browser approval.
- Desktop clients use a downloaded plugin or installer.
- Hosted agents connect to an MCP gateway URL.

For a client without a dedicated guide, start with [Connect Your Agents](/docs/get-started/connect).
