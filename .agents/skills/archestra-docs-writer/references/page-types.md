# Page Types

Adapted and shortened for Archestra from GitHub's documentation-writer skill (MIT; see [attribution](attribution.md)).

Choose one primary purpose for a page:

| Type        | Reader's Goal                     | Include                                                           |
| ----------- | --------------------------------- | ----------------------------------------------------------------- |
| Tutorial    | Learn by completing a first task  | Prerequisites, one guided path, observable result, next step      |
| How-to      | Complete a known task             | Required inputs, direct steps, verification, relevant constraints |
| Reference   | Look up exact behavior            | Parameters, defaults, limits, permissions, examples where useful  |
| Explanation | Understand concepts and tradeoffs | Relationships, rationale, diagrams, links to procedures           |

Keep long reference details out of tutorials. Link between types rather than mixing unrelated journeys. Use the requested scope and existing context; routine edits do not require another outline approval.
