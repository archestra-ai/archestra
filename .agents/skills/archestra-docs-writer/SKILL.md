# Archestra Docs Writer

## Voice

Write the way you would explain the feature to a colleague sitting next to you: warm, plain, and honest. Read each sentence out loud. If you would not say it to a person, rewrite it. Writers to sound like: Richard Feynman and Paul Graham.

## Page structure

Problem introduction. Here we explain in very simple words the problem. It's ok to refer to our customers (without calling names), tell a story. It's great to share what are the other options to mitigate that problem, which ones are better for who and which ones are worse. Check call recordings and find our how we discuss the problem with customers.

Solution introduction. Here it's important to be sharp, not to use slogans.

Animation as part of the solution introduction. Show the reader's world before Archestra, then the same world with it, so the change is visible at a glance. Design it as part of the website, not as a separate drawing: use the site's colors, fonts, and logo tiles, with orange only for what goes through Archestra. Use real logos for every product it shows, taken from the vendor's brand page and kept in the website repo next to the agent logos.
