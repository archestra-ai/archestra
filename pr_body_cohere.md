# PR Description - Add Cohere Provider Support

## Overview
This PR implements full support for the Cohere LLM provider using its V2 Chat API. Unlike previous OpenAI-compatible integrations, this required a custom adapter implementation to handle Cohere's specific request/response/stream structures.

## Key Changes

### Backend Implementation
- **Custom Adapters**: Developed `CohereRequestAdapter`, `CohereResponseAdapter`, and `CohereStreamAdapter` to bridge Cohere's V2 API with Archestra's generic LLM proxy.
- **Direct Streaming Support**: Implemented manual SSE parsing for Cohere's stream chunks, ensuring compatibility with the existing observability layer.
- **Proxy Routes**: Added `/v1/proxy/cohere/chat` and `/v1/proxy/cohere/:agentId/chat` routes with full agent support.
- **Type Definitions**: Added Zod schemas for all Cohere V2 message, tool, and API types.
- **Configuration**: Added `ARCHESTRA_COHERE_BASE_URL` and `ARCHESTRA_CHAT_COHERE_API_KEY` to the configuration system.

### Frontend Integration
- **Interaction Handler**: Created `CohereChatCompletionInteraction` to handle the display of conversations and tool calls generated by Cohere models.
- **UI Registration**: Registered the new provider in `interaction.utils.ts` and updated shared model constants.

### Shared Constants
- Added `cohere` to `SupportedProvidersSchema`.
- Defined `cohere:chat` as a supported discriminator.
- Updated `providerDisplayNames` for the UI.
