# Weather UI MCP Server

Example MCP server demonstrating MCP-UI integration with Archestra.

## Features

- Interactive weather widget with gradient design
- 3-day forecast display
- Refresh button that triggers tool call
- Beautiful glassmorphism UI

## Installation

```bash
npm install
```

## Usage

Add to your Archestra MCP catalog or test directly:

```bash
npm run dev
```

## Tool

**`get_weather_ui`**
- Input: `{ city: string }`
- Returns: Interactive weather UI widget

## Example Cities

- New York
- London
- Tokyo
- Sydney
