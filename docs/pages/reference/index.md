Reference pages list exact values to look up: environment variables, API endpoints, built-in MCP tools, permissions, and the Apps SDK.

Most platform operations have three entry points: the web UI, the [platform API](/docs/reference/api) for scripts and CI, and the [Archestra MCP Server](/docs/reference/archestra-mcp-server) tools an agent calls. All three check the same role [permissions](/docs/reference/permissions). Deployment-wide settings that the UI does not expose are [environment variables](/docs/reference/configuration). MCP Apps call platform tools through the [Apps SDK](/docs/reference/apps-sdk), as the viewing user.
